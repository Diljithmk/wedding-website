# LUMIÈRE & CO. — Luxury Wedding Photography & Cinematography Website

A modern, responsive, and luxury editorial website for wedding photography and cinematography studios. Built with React, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Editorial Luxury Design**: Tailored typography with Cormorant Garamond & Plus Jakarta Sans, refined color palette, and bespoke aesthetic.
- **Interactive Portfolio & Gallery**: Filterable showcases, high-resolution imagery, and masonry layouts.
- **Cinematic Experience**: Hero showcases, film reels, and storytelling layouts.
- **Investment & Packages**: Transparent package tiers, transparent pricing details, and bespoke add-on options.
- **Booking & Inquiry Form**: Interactive inquiry flow with date pickers, budget selectors, and venue inputs.
- **Fluid Micro-Animations**: Smooth scroll and motion transitions powered by Framer Motion.
- **Fully Responsive**: Optimized for ultra-wide desktop, tablet, and mobile devices with local network preview support.

## 🚀 Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS 3**
- **Framer Motion**
- **Lucide React**

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

To expose it over your local Wi-Fi / network:
```bash
npm run dev -- --host
```

### 3. Build for Production
```bash
npm run build
```
